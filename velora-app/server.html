Velora Server for Mac

The server is a Mac app.

Not a web page in a box: a native macOS app that sets up in a few steps, keeps your library tidy, and tells you exactly what it's doing.

Download for MacSetup guide
Setup

Three steps.

Create the admin account, link your media folders, and open the app on your devices. Velora recognises movies, series, music, audiobooks, books, papers, manga and sheet music in the usual folder layouts, including Jellyfin's and Plex's. The guide to organizing your media shows the layout that works best.

Libraries

Folders on any drive, read only.

Add folders from several drives to one library. Velora reads your files and never writes to them; artwork, previews, conversions and generated audio live in Velora's own data folder.

  • Rescan one library or all
  • Metadata and artwork from TMDB, TVmaze, MusicBrainz, Open Library, AniList, MangaDex, arXiv and more, each switchable
  • Lookups send titles and IDs, never file paths
AI

Every model in one place.

The AI page lists language model connections (Nativ, Ollama or a cloud provider with your own key), the EmbeddingGemma 2 recommendations model, YuE2-3B for music, and the narration voices, with the memory each one needs.

Everything on the server

What the Mac app manages

Overview

Streams right now, recent activity, library counts and outbound traffic at a glance.

Live Traffic

Every stream, request and device, updated every second, as lanes or a map.

Users and devices

Accounts, roles, per-library access, who may create audio or music, and every signed-in device you can revoke. Each person's playback settings are kept in their account.

Playback

Direct play versus conversion, hardware transcoding with VideoToolbox, and a request log with Show Logs.

Storage

How much each library and each cache uses, with one-click cleanup of caches Velora can rebuild.

Activity

Scans, metadata, previews, embeddings, narration, music and score-reading jobs, with pause, retry and cancel.

Integrations

TMDB key, metadata providers, and the MCP server for AI assistants with scoped tokens.

Review

Suggested titles, matches and tags from library cleanup, to accept, edit or undo.

The wall-mount dashboard in the web app was removed in 2.6. Live Traffic stays in the Mac app.
