Troubleshooting

My Mac doesn't show up in the app

Check that the device and the Mac are on the same network and that Velora Server is running (the sidebar says Running). Some routers block discovery between Wi-Fi and Ethernet; enter the address by hand: http://<your-mac>.local:8420. Allow Velora when iOS asks for Local Network access.

A video won't start or keeps loading

Tap Retry. If the file needs converting, make sure ffmpeg is installed. The server's Playback page has Show Logs with the request log. Image subtitles (PGS, VobSub) are burned in and start more slowly; pick a text subtitle if there is one.

Posters or covers are missing

Movie posters need a free TMDB key under Integrations. Check that the providers you want are switched on, then use Rescan. Local poster.jpg and cover.jpg files always win.

Episodes are in the wrong order or have no titles

Name files Show - S01E01 - Title.mkv inside Season 01 folders, or add .nfo files. Then rescan the library. If every episode has the name of a different one, the discs follow another order than TMDB: set the show's episode order in Velora Server.

Lyrics don't appear

Put an .lrc file with the same name next to the song, or embed lyrics in the file. Velora reads lyrics from local files only.

Recommendations are empty

Recommendations need some history: watch, listen or read a few things. The model downloads on first use (see Activity). On a Jellyfin, Plex or Navidrome server, Velora's recommendations are not available.

Music generation is slow or won't start

Only one song is made at a time, and jobs pause while a video streams. Check the schedule on the Music Generation page and the daily limit for your account. A lower precision (4-bit) uses less memory.

Create Audio fails at the script step

Check the language model connection on the AI page. For Ollama, make sure it is running on the Mac. The job shows a readable error on the Activity page and can be retried.

Other server says nothing answered at that address

Check that the server is running and reachable from this device. If it uses a custom port, add it to the address (for example nas.local:9000), or pick the server type from the menu next to the address.

I can't sign in to a Jellyfin server

Use the address with port 8096 (or your custom port) and your Jellyfin username. The app checks /System/Info/Public to reach the server.

I can't sign in to a Plex server

Approve Velora on plex.tv, or enter the code at plex.tv/link before it expires (a few minutes), then try again. If Velora can't reach the server, check that it is running and, away from home, that Remote Access is on in Plex.

I can't sign in to a Navidrome server

Use the address with port 4533 (or your custom port) and your Navidrome username. The app signs in with /rest/ping. Servers that can't check tokens (some LDAP setups) are signed in with the encoded password instead.

I forgot the admin password

Reset it on the Mac itself from Velora Server's sign-in screen. It can't be reset over the network.

After updating, my library looks out of date

Open Velora Server and click Rescan All.
