MCP setup

Velora includes a Model Context Protocol server so an AI assistant you run can search your library, see what's playing and control playback.

MCP is off by default. Turn it on under Integrations in Velora Server and create a token with the narrowest scope you need: read, playback or admin.

Claude Code

claude mcp add --transport http velora http://my-mac.local:8420/mcp --header "Authorization: Bearer <token>"

Other clients

Any MCP client that supports Streamable HTTP can connect to http://<your-mac>:8420/mcp with the token as a bearer token.

Safety

  • No tool deletes anything.
  • Library access follows the token's user and scope.
  • Remote-control tools are rate-limited.
  • MCP requests are labelled in Live Traffic and Activity.
