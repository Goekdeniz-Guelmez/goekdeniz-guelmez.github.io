Set up Velora

Velora has two parts: Velora Server, a Mac app that holds your library, and the Velora apps on your other devices. Setup takes a few minutes.

You need an Apple silicon Mac with macOS 26 or later. See System requirements.

1. Install Velora Server

Download VeloraServer.dmg, open it, and drag Velora Server into Applications. The app is notarized by Apple.

2. Create the admin account

On first launch Velora Server asks for an admin username and password. The password is stored as a secure hash on this Mac. If you forget it, you can reset it on the Mac itself, never over the network.

3. Link your media folders

Choose folders on any drive. Velora detects movies, series, music, audiobooks, books, papers and manga inside them. You can skip this and add folders later. See Adding media folders.

4. Connect your devices

Open the Velora app on your iPhone, iPad, Mac, Apple TV or Vision Pro. Your server appears under On this network. Pick it, sign in once, and the device stays connected. In a browser, open http://<your-mac>.local:8420 for the web app.

5. Optional extras

  • Add a free TMDB key under Integrations for the best movie posters.
  • Install ffmpeg so Velora can convert formats your devices can't play directly.
  • Set up AI models for recommendations, Create Audio and music generation.
  • Add users for the rest of your household.
