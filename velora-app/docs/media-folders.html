Organizing your media

Velora reads your files where they are. It never renames, moves or writes into your media folders, so the way you name and arrange them is what Velora goes by. A few simple habits give you the right titles, posters, episode order and extras on the first scan, with nothing to fix afterwards.

Already using Jellyfin, Plex or Kodi? Keep your folders as they are. Velora reads the same layout: season folders, .nfo files, poster.jpg, Extras folders and the rest.

The six rules

  1. One folder per kind of media. Movies, shows, music, audiobooks, books, papers, manga and sheet music each get their own top folder, and each becomes its own library.
  2. One folder per title. A folder for each movie, each show, each album and each audiobook. Extras, artwork and subtitles then belong to the right title.
  3. Put the year in the name. Ember Coast (2019) finds the right film among remakes and films of the same name.
  4. Number your episodes. S01E01 in the file name, inside a Season 01 folder.
  5. Give bonus material its own folder. Extras/ for making-ofs and trailers, backdrops/ for a moving background.
  6. Name extra files like the file they belong to. Ember Coast (2019).en.srt next to Ember Coast (2019).mkv.

When you link Velora-Media in Velora Server, it suggests one library per subfolder and takes each library's type from the folder's name. You confirm or change the type before anything is scanned.

For the best performance

  • Video: H.264 or HEVC in MKV or MP4 is never re-encoded; Velora only repackages it for the device, so it starts in well under a second.
  • Audio: AAC, AC-3 (Dolby Digital), E-AC-3, ALAC, FLAC, MP3 and PCM play as they are. DTS and TrueHD are converted while you watch, on the Mac's hardware media engine. That's quick, but files whose audio needs no conversion start fastest and use the least power.
  • Subtitles: text subtitles (SRT, ASS, WebVTT, or text tracks inside the file) switch on instantly. Image subtitles from discs (PGS, VobSub) have to be burned into the picture, which starts more slowly.
  • Chapters: MKV chapters named Opening or Intro and Ending or Credits give Skip Intro and Skip Credits straight away. See Shows.
  • Drives: an SSD, or a drive that doesn't spin down, starts videos and finishes scans fastest. If a drive is unplugged, its titles are hidden and come back with their progress when it's connected again.
  • The first scan: titles appear within minutes; details, artwork, scrubbing thumbnails and recommendations follow in the background. Follow them on the Activity page. You can watch while it works.

One library, several drives

A library can hold folders on several drives, for example Movies on an external SSD and on the Mac's own disk. Use the same layout in each and add both to the same library; Velora shows them as one. Don't link a folder that sits inside another linked folder.

What Velora skips

Hidden files and folders (names starting with a dot), and the working folders other apps leave on a drive: metadata, config, cache, transcodes, backups, navidrome-data, extrafanart, .actors, *.trickplay, @eaDir, #recycle, lost+found and photo caches. A Jellyfin, Kodi, Navidrome or Synology folder on the same drive does no harm.

Renaming and reorganizing later

You can rename and move files at any time. A file renamed or moved on the same drive keeps its progress, watched state, highlights and details. Click Rescan on the library so Velora reads the new name. A file copied to another drive counts as a new file.
