Adding media folders

Velora reads media from folders you link in Media Folders or Libraries in Velora Server. A library has a type and one or more folders, which can be on different drives.

Velora never writes to your media folders. Artwork, previews, conversions and generated audio go into Velora's own data folder.

Library types

TypeFilesRecommended layout
MoviesMKV, MP4, MOV and moreMovies/Title (Year)/Title (Year).mkv
SeriesAs moviesShows/Show (Year)/Season 01/Show - S01E01 - Title.mkv
MusicM4A, MP3, FLAC, ALAC, WAVMusic/Artist/Album/01 Song.m4a, with cover.jpg and optional .lrc lyrics
AudiobooksM4B, M4A, MP3Audiobooks/Author/Title/, one M4B with chapters or one file per chapter
BooksEPUB, PDFBooks/Author - Title.epub
PapersPDFPapers/, grouped by subject automatically
MangaImage folders, CBZManga/Series/Volume 01/

What Velora reads next to your files

  • .nfo files (Jellyfin and Kodi style) for titles, plots and episode names.
  • poster.jpg, fanart.jpg, cover.jpg and other local art.
  • Chapters, audio and subtitle tracks inside the file, plus external .srt subtitles.
  • .lrc files for synced lyrics.

Online metadata

Velora can fill in posters, cast, album art and book covers from TMDB, TVmaze, Kitsu, AniList, MusicBrainz, Cover Art Archive, TheAudioDB, Open Library, Google Books, arXiv, Crossref and MangaDex. Each provider can be switched off under Integrations. Lookups send titles and IDs, never file paths, names, sizes or hashes.

Rescanning

New files are picked up by a scan. Use Rescan on a library, or Rescan All. Previews, metadata and recommendations then update in the background; follow them on the Activity page.
