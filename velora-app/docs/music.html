Music and audiobooks

Music goes Artist/Album/, audiobooks go Author/Title/. Good tags inside the files help too: Velora reads both.

Music

Music/
└── Mira Vale/                                  ← artist
    └── Lowlight (2024)/                        ← album (year optional)
        ├── cover.jpg
        ├── 01 Lowlight.flac
        ├── 01 Lowlight.lrc                     ← synced lyrics
        ├── 02 Glass Harbour.flac
        └── 03 Slow Tide.flac
  • Start song names with the track number: 01 Title, 01 - Title or 01. Title. An artist in the name (01 Mira Vale - Lowlight) is removed from the title.
  • The album folder may carry the year: Lowlight (2024) shows as Lowlight.
  • Compilations and soundtracks work best in a folder per album under Various Artists or the composer.

Albums with several discs

Use Disc 1, Disc 2 folders (also CD1, Disk 2, or Disc 1 - Subtitle), or a disc number before the track: 1-01 Title.flac. Either way it stays one album with disc headings, never “Disc 1” as an album.

Mira Vale/
└── Tidal Hours (2025)/
    ├── folder.jpg                              ← cover for both discs
    ├── Disc 1/
    │   ├── 01 Opening.m4a
    │   └── 02 Undertow.m4a
    └── Disc 2/
        └── 01 Night Side.m4a

Album covers

Velora takes the first it finds: a picture in the album folder named cover, folder, front, album or albumart (a folder.jpg above the disc folders counts), then art embedded in the files, then MusicBrainz and the Cover Art Archive if they're switched on. Online art never replaces your own.

Lyrics

Put a .lrc file with the same name next to the song for lyrics that scroll in time; word-by-word timings work too. Velora also reads lyrics embedded in the file, and a plain .txt file with the same name. Lyrics are read from your files only, never fetched online.

Audiobooks

Audiobooks/
└── Lena Hart/                                  ← author
    ├── Ember Coast Stories (2023)/             ← one M4B with chapters
    │   ├── cover.jpg
    │   └── Ember Coast Stories.m4b
    └── The Long Tide/                          ← one file per chapter
        ├── cover.jpg
        ├── 01 Arrival.mp3
        ├── 02 The Harbour.mp3
        └── 03 Departure.mp3
  • Best: one M4B file with chapters inside. Chapters, title and narrator come straight from the file.
  • Also fine: one file per chapter in the book's folder, numbered so they sort in order (01, 02, … not 1, 10, 2). Each file becomes a chapter; a file with chapters of its own keeps them.
  • The folder names the book and the folder above it names the author. The narrator comes from the file's tags (narrator, composer or performer).
  • M4B files are audiobooks wherever they are. MP3 and M4A files count as audiobooks inside an Audiobooks library.
