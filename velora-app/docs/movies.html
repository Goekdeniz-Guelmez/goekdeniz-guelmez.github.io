Movies

Give every movie its own folder named Title (Year), with the film inside under the same name. Everything else in this guide is optional, and makes a good library great.

The basic layout

Movies/
├── Ember Coast (2019)/
│   └── Ember Coast (2019).mkv
└── The Quiet Orchard (1988)/
    └── The Quiet Orchard (1988).mp4
  • Use the title as TMDB knows it, in English or in the original language. Velora looks up the title and the year, never the file path.
  • The year can be written (2019), [2019] or .2019.. If the file name has none, Velora takes it from the folder.
  • Release names such as Ember.Coast.2019.1080p.BluRay.mkv work, but a clean name matches more reliably.
  • Several movies loose in one folder are fine for a quick start, but versions, extras and artwork need one folder per movie.

A complete movie folder

Ember Coast (2019)/
├── Ember Coast (2019).mkv                      ← the film
├── Ember Coast (2019) - Director's Cut.mkv     ← a second version
├── Ember Coast (2019).en.srt                   ← subtitles
├── Ember Coast (2019).de.forced.srt
├── poster.jpg                                  ← artwork
├── fanart.jpg
├── logo.png
├── movie.nfo                                   ← optional details
├── backdrops/
│   └── Backdrop.mkv                            ← moving backdrop
└── Extras/
    ├── Making Of.mkv
    ├── Storyboard Version.mkv
    └── Teaser Trailer.mkv

Versions and editions

Several files of the same film in one folder become one movie with a version picker. Name each extra version after the folder, then - and a label; the label is what the picker shows.

Ember Coast (2019)/
├── Ember Coast (2019).mkv                      ← main version (no label)
├── Ember Coast (2019) - Director's Cut.mkv     ← “Director's Cut”
├── Ember Coast (2019) - 4K.mkv                 ← “4K”
└── Ember Coast (2019) {edition-Extended}.mkv   ← Plex style, “Extended”
  • The file without a label is the main version and is the one listed in the library. Without an unlabelled file, Velora prefers the one named exactly like the folder, then the largest.
  • Two films of 40 minutes or more without labels become “Version 2” and so on. A copy whose audio is a commentary track is listed as “Commentary”.
  • Plex's {edition-…} labels work as they are.

Movies split into parts

A film split across files is kept in order as parts, not versions: end each name with part1, cd1, disc 1 or pt1.

The Long Voyage (1962)/
├── The Long Voyage (1962) - part1.mkv
└── The Long Voyage (1962) - part2.mkv

Extras

Making-ofs, trailers, deleted scenes and interviews go into an Extras folder inside the movie's folder. They appear on the movie's page under Extras, not in your library. The file name becomes the extra's title, so name them the way you want to read them.

These folder names all work: Extras, Featurettes, Behind The Scenes, Deleted Scenes, Interviews, Scenes, Shorts, Trailers, Clips, Bonus, Other, Samples.

Or leave the extra next to the film and end its name with a Plex-style suffix; the suffix is dropped from the title:

Ember Coast (2019)/
├── Ember Coast (2019).mkv
├── Making Of-featurette.mkv       ← extra “Making Of”
└── Teaser-trailer.mkv             ← extra “Teaser”

Suffixes: -trailer, -featurette, -behindthescenes, -deleted, -deletedscene, -interview, -scene, -short, -clip, -extra, -other, -sample.

Extras attach to a movie only when its folder holds one movie. In a shared folder they appear as separate videos.

Moving backdrops

A short looping video, such as a Blu-ray's menu loop, can play behind the movie's page in place of the still backdrop (with sound on Apple TV). Put it in a backdrops folder and name it Backdrop:

Ember Coast (2019)/
├── Ember Coast (2019).mkv
└── backdrops/
    └── Backdrop.mkv
  • Backdrops are hidden from the library and from Extras.
  • A file named Backdrop or Menu (Ember Coast (2019) - Backdrop.mkv), or anything in a backdrops or menu folder, counts as a backdrop. With several, the one named Backdrop plays.
  • Keep it short: 20 seconds to a few minutes, made to loop.

Disc rips (MakeMKV)

MakeMKV names its files title_t00.mkv, title_t01.mkv and so on. Velora copes with a folder of unnamed rips: beside a feature-length film, titles under 10 minutes whose audio has no language are treated as menu loops and hidden, and the other short titles become “Extra 1”, “Extra 2” on the film's page.

For the best result, rename them before you add them:

Rip titleRename to
The feature (the longest title)Ember Coast (2019)/Ember Coast (2019).mkv
The menu loop (short, still or looping picture, no spoken language)backdrops/Backdrop.mkv
Making-ofs, storyboards, trailers for this filmExtras/<what it is>.mkv
Trailers for other films, ads, test patternsLeave them out

Artwork

Pictures in the movie's folder always win over pictures from the internet. JPG, PNG, WebP and HEIC all work, in upper or lower case.

PictureFile names (first match wins)
Poster (2:3)<file>-poster, poster, movie, folder, cover
Backdrop (16:9)<file>-fanart, <file>-backdrop, fanart, backdrop, background, art, landscape
Title logo (transparent PNG)<file>-logo, logo, clearlogo

<file> is the video's name without the extension, for example Ember Coast (2019)-poster.jpg. Without local art, Velora uses a cover inside the MKV, then TMDB (with a free key under Integrations).

Details from .nfo files

A Kodi or Jellyfin .nfo file next to the film sets its title, plot and IDs: <file>.nfo, or movie.nfo in the movie's folder. With a TMDB or IMDb ID inside, the match is exact.
