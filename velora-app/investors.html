For investors

The home media server for the Apple household.

Hundreds of millions of people live inside Apple's ecosystem, and many of them own a Mac that sits idle most of the day. Velora turns that Mac into a private media server with apps on every Apple screen, without a cloud to run and without a company account.

The problem

Personal media servers today are built to run everywhere, so they feel native nowhere. Apple users put up with cross-platform apps, company accounts in the middle of their own media, and features locked behind subscriptions.

The product

A native Mac server plus SwiftUI apps for iPhone, iPad, Mac, Apple TV and Vision Pro, a web app and a wall dashboard. Video, music, audiobooks, books and papers in one library.

Why now

Apple silicon put a hardware media engine and a capable neural engine in every Mac sold since 2020. Velora uses both: VideoToolbox for transcoding, MLX for on-device audio generation.

Differentiation

What no one else does

  • Apple-only by choice. One design language across six surfaces, using platform features such as Live Activities, Top Shelf, SharePlay, Vision Pro environments and CarPlay.
  • On-device AI that's actually useful. Create Audio turns any document into a narrated audiobook or a two-host conversation, privately on the user's Mac.
  • Agent-ready. A built-in MCP server makes a personal library usable by AI assistants, with scoped, non-destructive access.
  • Private by architecture. No Velora cloud means no hosting cost that grows per user, and no user data held by us.
Status

Where Velora is today

  • Velora Server 2.4.0 for Mac is released, notarized by Apple.
  • Apps for iPhone, iPad, Mac, Apple TV and Vision Pro are in TestFlight beta, and CarPlay is awaiting Apple's approval.
  • Available in English, German and Japanese.
Next
